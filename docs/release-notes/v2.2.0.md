## 2.2.0 — Mac 工作台与 Linux 远程项目

由 yatotm/chat-on-steroids fork 发布，基于上游 2.1.26 系列代码。

- 新增远程项目入口，连接 Linux 开发机 CodexPro 并验证项目目录。
- 复用 Plugins 传输、系统凭据存储和工具记录，支持 SSH 转发或 HTTPS。
- 每次调用绑定准确工作区，禁止远程项目误用 Mac 本地文件和命令工具。
- worker 与 Compact & Resume 保留远程项目；远程进程按本地会话隔离。
- 远程项目无需批准 Mac 目录，断线不回退到本机或自动重放调用。
- 更新与扩展下载地址切换到本 fork。

Apple Silicon Mac 请下载 **Chat-On-Steroids-macOS-arm64.dmg**。macOS 15.7.7 满足包声明的最低版本要求。包沿用上游未公证分发方式。

[远程开发配置说明](https://github.com/yatotm/chat-on-steroids/blob/v2.2.0/docs/remote-development.md)

Files、Review 和手动终端仍访问本机，远程操作与结果通过聊天工具展示。浏览器和 ChatGPT 登录在 Mac 运行。真实 Mac 15.7.7 与私人 ChatGPT 账号的完整流程需要安装后验证，构建和自动化检查不能代替这项验证。
