## 2.2.1 — 首次设置直接连接 Linux 开发机

修复 2.2.0 首次启动进入连接设置后，远程入口藏在聊天侧栏、第一步仍只提示选择本机目录的问题。

- 第一步改为“选择工作位置”，直接点击 **连接 Linux 开发机** 即可添加远程项目，无需选择 Mac 文件夹。
- 添加成功显示“已添加远程项目”，第一步计为完成；取消和连接失败不会误报成功。
- 第 5 步增加 Plugins 配置入口；远程项目需要 Core 和 Plugins 都连通。
- 聊天侧栏地球按钮继续可用，本机文件夹设置保持可用。

Apple Silicon Mac 下载 **Chat-On-Steroids-macOS-arm64.dmg**，退出旧版后替换应用即可，已有设置保留。最低 macOS 13，沿用未公证分发方式。

[中文配置说明](https://github.com/yatotm/chat-on-steroids/blob/v2.2.1/docs/remote-development.md)

已添加远程项目只表示 CoS 验证了开发机目录；仍需完成 ChatGPT 连接和 Chrome 扩展设置后才能对话执行任务。
