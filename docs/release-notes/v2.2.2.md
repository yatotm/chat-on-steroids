## 2.2.2 — SSH 开发机连接与独立远程 Core

这是本地开发构建的说明，尚未发布版本。

- 选择 SSH 配置中的主机，CoS 自动管理连接；同一开发机的多个项目共享一条映射并复用安全保存的令牌。
- 以条目管理允许访问的远端目录，单独选择主项目目录，并可明确创建尚不存在的项目目录。
- 侧栏分开显示远程开发机和本地项目，提供已验证的连接状态、刷新、重连与连接设置。
- 启用受管 SSH 后，关闭窗口直接退出应用，清理 CoS 创建的映射。用户手动 SSH、独立 CodexPro 连接保持各自的所有权。
- 远程工具统一通过 Mac CoS Core 路由到 Linux；无需额外的 Plugins 连接器或 Plugins tunnel。修正未启用 Plugins 的误报和纯远程项目的权限诊断。
- 同步上游 `totec448-spec/chat-on-steroids` 至 `a8161d6`，纳入新的浏览器选项、搜索、重命名、图片保存、Skills 与会话修复。原图保存也支持远程项目。

执行服务协议升级为 2，Mac 应用和 Linux 执行器需要配套更新。旧项目在明确选择 SSH 主机并核对服务身份后迁移，保留项目和聊天身份。执行器重启后旧进程句柄失效。

目录列表约束文件工具和命令的初始工作目录；Shell 命令使用开发机账户的系统权限。Files、Review 和手动终端面板仍属于本机工作区。

实际检查及尚未覆盖的情形见本轮工作记录；本说明本身不代表构建、安装或用户账户下的完整验收已完成。
