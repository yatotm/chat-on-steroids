# 2026-10-04：Mac 工作台与 Linux 远程开发

以 fork 的 `c535875` 为基底，在隔离工作目录开发。复用现有 Plugins 连接 CodexPro；项目目录、插件 UUID、服务地址指纹和工作区 ID 标识执行目标，目录权限仍由开发机管理。

- 项目增加远程绑定，输入、提示、worker 与接续复用原有身份。
- 调用注入工作区，拒绝跨工作区、默认目录切换和 wrapper 绕行。
- Core 在执行前拒绝远程项目的本机文件与命令操作，执行目标需要精确会话证据。
- `remote-process-owners` 保存进程归属，实际进程仍由开发机管理。
- 界面复用 Plugins 安装、凭据和连接状态；不维护第二套连接或密码表。
- fork 更新源、扩展下载地址同步更改，标签触发原生构建与发布。
